스마트 주차장 프로젝트 인수인계 보고서
최종 갱신일: 2026-06-14

1. 프로젝트 개요

이 프로젝트는 Arduino Uno 3대와 Node.js 서버를 이용해 스마트 주차장의 입구, 주차칸, 출구 LCD를 분리 구현한 실습 프로젝트다.
초기에는 Uno 3에서 입구 LCD와 출구 LCD를 모두 처리했지만, 현재는 출구 LCD만 남기고 입구 LCD 로직을 제거했다.
프로젝트 방향도 입구 안내보다 출차 요금 표시와 상태 확인에 맞춰 단순화했고, 최근에는 웹 기반 관리자 페이지를 추가해 실시간 운영 화면까지 포함하는 구조로 확장했다.

2. 현재 구조

- Arduino Uno 1: 입구/출구 조도센서, 입구/출구 차단기
- Arduino Uno 2: 주차칸 2개 감지와 LED 상태 표시
- Arduino Uno 3: 출구 LCD 전광판
- Node.js 서버: 시리얼 중계, 주차 상태 저장, 요금 계산
- 관리자 페이지: 실시간 주차 현황, 경과 시간, 발생 요금, 요금 정책 표시

3. 방향 전환 기록

처음에는 입구 LCD와 출구 LCD를 함께 보여주는 구조였다.
하지만 실제 구현과 배선 난이도를 줄이기 위해 Uno 3를 출구 LCD 전용으로 바꿨다.
이후 입구 LCD 관련 명령, 배선 설명, 테스트 스케치, 회로도는 정리해서 제거했다.
현재 LCD는 출차 시점의 요금과 주차 현황만 보여준다.
최근에는 관리자 페이지 UI를 별도 폴더로 분리했고, 실시간 테이블형 주차칸 모니터링, 테마 전환, 요금 기준 안내까지 추가했다.

4. 현재 동작 흐름

1. Uno 1이 입구 조도센서로 차량을 감지한다.
2. Node.js 서버가 저장한 빈자리 수를 바탕으로 차단기 열림 여부를 판단한다.
3. Uno 2가 주차칸 2개의 점유 여부를 관리한다.
4. 차량이 들어가면 입차 시각을 서버에 저장한다.
5. 차량이 빠지면 출차 대기 상태로 바꾼다.
6. Uno 1 출구 조도센서가 차량을 감지하면 출차 이벤트를 발생시킨다.
7. Node.js 서버가 출차 대기 중인 칸의 요금을 계산한다.
8. Uno 3 출구 LCD에 현재 주차 현황과 출차 요금을 표시한다.
9. 관리자 페이지에서 주차칸별 상태, 진입 시간, 경과 시간, 발생 요금을 실시간으로 렌더링한다.

5. 주요 파일

- `sketches/uno_gate/uno_gate.ino`
  - 입구/출구 조도센서와 차단기 제어
  - 빈자리 수를 받아 입구 개방 여부를 판단

- `sketches/uno_slots/uno_slots.ino`
  - 주차칸 2개의 초음파센서와 LED 표시
  - `ENTRY`, `VACATED` 이벤트를 서버에 전송

- `sketches/uno_lcd/uno_lcd.ino`
  - 출구 LCD만 담당
  - `LCD_STATUS`, `LCD_EXIT_FEE`만 처리

- `요금 (NodeJs Server)/fee-server/src/server.js`
  - Uno 1, Uno 2, Uno 3를 USB Serial로 연결
  - 주차 상태 저장
  - 요금 계산 후 LCD 표시 명령 전송

- `관리자 페이지 (NodeJs Server)`
  - `/admin` 화면 정적 리소스
  - 로그인 후 실시간 대시보드 표시
  - 주차칸 상태 테이블, 요금 기준 블록, 테마 전환 제공

7. 현재 기준 값

- 입구 서보모터 이동 시간: `100ms`
- 출구 서보모터 이동 시간: `200ms`
- 주차칸 감지 거리: 1번 `16cm`, 2번 `10cm`
- 조도센서 차단 임계값: `200`
- 요금 기준: `30분 1000원`, 이후 `10분당 500원`

8. 시리얼 포트

- Uno 1: `GATE_SERIAL_PORT=COM3`
- Uno 2: `SLOT_SERIAL_PORT=COM5`
- Uno 3: `LCD_SERIAL_PORT=COM7`
- Baud: `9600`
