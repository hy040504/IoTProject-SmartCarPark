스마트 주차장 프로젝트 인수인계 보고서
작성일: 2026-06-11

1. 프로젝트 개요

본 프로젝트는 Wemos D1 R1 보드를 기반으로 한 스마트 주차장 시스템이다.
입구에서는 조도센서로 차량 접근 여부를 판단하고, 내부 주차칸 2개는 초음파센서로 점유 여부를 확인한다.
빈자리가 있으면 LCD에 Entrance Open을 표시하고 입구 차단기를 열며, 만차이면 LCD에 Parking Full을 표시하고 LED 또는 부저로 경고한다.
주차 시간과 요금 계산은 별도의 Node.js Express 서버가 담당한다.

2. 현재 구현된 전체 흐름

현재 보드 구성:
- Arduino Uno 1: sketches/uno_gate/uno_gate.ino 업로드, 입구/출구 조도센서, 입구/출구 차단기, LCD, 만차 경고 담당
- Arduino Uno 2: sketches/uno_slots/uno_slots.ino 업로드, 주차칸 2개 초음파센서와 칸별 LED 담당
- Wemos D1 R1 1: sketches/wemos_gateway/wemos_gateway.ino 업로드, Uno 이벤트와 요금 서버 사이의 게이트웨이 담당
- Wemos D1 R1 2: sketches/wemos_monitor/wemos_monitor.ino 업로드, 서버 상태 모니터링 담당

루트에는 통합 실행용 ino 파일을 두지 않는다.
프로젝트가 4개 보드로 나뉘면서 실제 업로드 대상은 sketches 폴더 안의 보드별 ino 파일이다.
BOARD_UPLOAD_GUIDE.md는 각 보드에 어떤 스케치를 업로드해야 하는지 안내하는 문서이다.

1) 입구/출구 차량 감지
- 조도센서 2개가 각각 입구 차량과 출구 차량을 감지한다.
- 평상시 조도 값은 400~500대이고 차량이 가리면 300대에서 200대 아래로 내려가는 값이 확인되었다.
- 현재 기준값은 LIGHT_BLOCKED_THRESHOLD = 350으로 설정되어 있다.

2) 주차칸 상태 확인
- 초음파센서 2개가 각각 1번, 2번 주차칸의 점유 여부를 확인한다.
- 주차칸/parking_slots.h에서 readSlotDistanceCm(), isSlotOccupied(), countEmptySlots()가 관련 로직을 담당한다.
- 차량 감지 기준 거리는 SLOT_OCCUPIED_DISTANCE_CM = 5cm이다.

3) 입차 가능 판단
- 입구에 차량이 있고 빈자리가 1개 이상이면 LCD에 Entrance Open을 표시한다.
- 만차 경고 LED/부저를 끄고, 입구 차단기 서보모터를 90도로 이동시켜 차단기를 연다.
- 이 흐름은 sketches/uno_gate/uno_gate.ino의 loop()에서 처리한다.

4) 만차 처리
- 입구에 차량이 있고 빈자리가 없으면 LCD에 Parking Full을 표시한다.
- 주차칸/parking_alert.h를 통해 만차 경고 LED/부저를 켠다.
- 입구 차단기를 닫힌 상태로 유지한다.

5) 입차 등록
- 차량이 실제 주차칸에 들어가면 해당 칸 초음파센서가 점유 상태로 전환된다.
- 해당 칸 빨간 LED가 켜지고 초록 LED는 꺼진다.
- 요금/fee_request.h의 sendVehicleEntryRequest(slotId)가 호출되어 Express 서버에 GET /parking/entry?slot=칸번호 요청을 보낸다.
- 서버는 해당 칸의 입차 시간을 메모리에 저장한다.

6) 2단계 출차 처리
- 1차 감지: 차량이 주차칸에서 빠지면 해당 칸을 출차 대기 상태로 저장한다.
- 이 시점에는 아직 서버에 출차 요청을 보내지 않는다.
- 2차 감지: 차량이 출구 조도센서를 가리면 Arduino Uno 1이 Wemos 게이트웨이에 BARRIER_EXIT 이벤트를 보낸다.
- Wemos 게이트웨이가 GET /parking/exit?slot=칸번호 요청을 보낸다.
- 서버 response에서 fee 값을 추출하고 LCD에 요금을 표시한다.
- 출차를 2단계로 나눈 이유는 초음파센서 흔들림이나 일시적 오감지를 바로 출차로 처리하지 않기 위해서이다.

3. 주요 파일 설명

BOARD_UPLOAD_GUIDE.md
- 보드별 업로드 대상 스케치를 안내하는 문서이다.
- 루트에는 실행용 ino 파일을 두지 않고, sketches 폴더의 보드별 ino 파일을 사용한다.

sketches/uno_gate/uno_gate.ino
- 입구 조도센서와 출구 조도센서를 각각 읽는다.
- 입구 차량 감지 시 빈자리 여부에 따라 입구 차단기를 제어한다.
- 출구 차량 감지 시 출구 차단기를 열고 Wemos 게이트웨이에 BARRIER_EXIT 이벤트를 보낸다.
- 조도센서 튜닝을 위해 입구/출구 조도 값을 시리얼 모니터에 주기적으로 출력한다.

주차칸/parking_slots.h
- 주차칸 2개의 초음파센서와 칸별 LED를 담당한다.
- 차량이 들어오면 입차 요청을 서버에 보낸다.
- 차량이 빠지면 pendingExitSlotId에 출차 대기 칸 번호를 저장한다.
- 차단기 통과가 감지되면 서버에 출차 요청을 보내고 LCD에 요금을 표시한다.

주차칸/parking_display.h
- I2C LCD 표시를 담당한다.
- Entrance Open, Parking Full, 출차 요금 메시지를 출력한다.
- 같은 메시지를 반복해서 clear하지 않도록 이전 메시지를 저장하여 LCD 깜빡임을 줄였다.

주차칸/parking_alert.h
- 만차 경고 LED와 부저를 제어한다.
- turnOnParkingFullAlert(), turnOffParkingFullAlert()로 상태를 변경한다.

차단기/barrier.h
- 이전 단일 보드 구조에서 사용하던 차단기 모듈이다.
- 현재 실제 업로드 구조에서는 sketches/uno_gate/uno_gate.ino가 입구/출구 차단기를 직접 제어한다.

요금/fee_request.h
- Wemos가 Wi-Fi에 연결하고 Express 서버에 HTTP GET 요청을 보내는 역할을 한다.
- Wi-Fi 이름, 비밀번호, 서버 주소는 이 파일 상단에서 수정한다.
- FEE_SERVER_BASE_URL은 서버 PC의 내부 IP로 바꿔야 한다.

요금/fee-server/src/server.js
- Node.js Express 기반 요금 계산 서버이다.
- /parking/entry, /parking/exit, /parking/sessions API를 제공한다.
- 현재 주차 세션은 메모리 Map에 저장되므로 서버를 재시작하면 기록은 초기화된다.

요금/fee-server/src/feeCalculator.js
- 주차 요금 계산 로직을 담당한다.
- 기본 30분 1000원, 이후 10분마다 500원을 추가한다.

4. 서버 API

GET /parking/entry?slot=1
- 1번 칸 입차 시간을 저장한다.

GET /parking/entry?slot=2
- 2번 칸 입차 시간을 저장한다.

GET /parking/exit?slot=1
- 1번 칸 출차 시간을 기준으로 요금을 계산한다.

GET /parking/exit?slot=2
- 2번 칸 출차 시간을 기준으로 요금을 계산한다.

GET /parking/sessions
- 현재 주차 중인 세션 목록을 반환한다.

5. 핀 설정

입구 조도센서: A0
출구 조도센서: A1
입구 차단기 서보모터: 9
출구 차단기 서보모터: 10
만차 경고 LED: 12
만차 경고 부저: 11
1번 칸 초음파 TRIG / ECHO: D6 / D3
2번 칸 초음파 TRIG / ECHO: D7 / D4
1번 칸 빨간 / 초록 LED: D9 / D10
2번 칸 빨간 / 초록 LED: D11 / D12
I2C LCD: SDA / SCL

주의: Wemos D1 R1 환경에서 D9~D12 핀명이 실제 보드 설정에 따라 다르게 동작할 수 있으므로 실제 업로드 전 보드 핀맵 확인이 필요하다.

6. 실행 방법

요금 서버 실행:
cd 요금/fee-server
npm install
npm start

Wemos 설정:
요금/fee_request.h에서 WIFI_SSID, WIFI_PASSWORD, FEE_SERVER_BASE_URL을 실제 환경에 맞게 수정한다.

Arduino 업로드:
Arduino IDE 또는 arduino-cli에서 각 보드에 맞는 스케치를 업로드한다.
- Arduino Uno 1: sketches/uno_gate/uno_gate.ino
- Arduino Uno 2: sketches/uno_slots/uno_slots.ino
- Wemos D1 R1 1: sketches/wemos_gateway/wemos_gateway.ino
- Wemos D1 R1 2: sketches/wemos_monitor/wemos_monitor.ino

부분 테스트:
- 현재 입구 조도센서, 출구 조도센서, LCD, 입구 차단기 서보, 출구 차단기 서보만 연결한 상태에서는 sketches/test/uno_gate_test/uno_gate_test.ino를 먼저 업로드한다.
- 해당 테스트 스케치는 Wemos 통신이나 주차칸 센서 없이 조도값 출력과 서보 열림/닫힘만 확인한다.

8. 현재 남은 작업 및 주의사항

1) 실제 하드웨어 핀맵 검증
- D9~D12 핀 사용 가능 여부를 실제 Wemos D1 R1 환경에서 확인해야 한다.

2) HC-SR04 전압 처리
- HC-SR04 ECHO는 일반적으로 5V 출력이다.
- ESP8266 입력은 3.3V 기준이므로 전압 분배 회로가 필요하다.

3) Wi-Fi 및 서버 IP 설정
- FEE_SERVER_BASE_URL의 192.168.0.10은 예시값이다.
- 실제 서버 PC의 내부 IP로 변경해야 한다.

4) 조도센서 기준값 튜닝
- 현재 기준값은 350이다.
- 평상시 값이 400~500대, 차량이 지나갈 때 300 이하로 내려가는 환경을 기준으로 설정했다.
- 설치 위치나 주변 조명에 따라 LIGHT_BLOCKED_THRESHOLD 값을 조정해야 한다.

5) 서버 데이터 영속화
- 현재 서버는 주차 기록을 메모리에 저장한다.
- 서버 재시작 후에도 기록을 유지하려면 JSON 파일, SQLite, MySQL 등 저장소 연동이 필요하다.

6) 한글 폴더명과 Arduino 컴파일 호환성
- 현재 모듈 폴더는 요청에 따라 차단기, 주차칸, 요금으로 정리되어 있다.
- Arduino CLI 1.5.1과 ESP8266 빌드 환경에서 한글 include 경로가 임시 빌드 폴더로 복사될 때 깨지는 문제가 확인되었다.
- 영어 폴더명 상태에서는 Wemos D1 R1 컴파일이 성공했지만, 한글 폴더명 상태에서는 include 경로 인코딩 문제로 컴파일이 실패한다.
- 실제 업로드 단계에서 같은 문제가 발생하면 폴더명을 barrier, parking, fee처럼 ASCII 이름으로 되돌리는 것이 가장 안전하다.
