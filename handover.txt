작성일: 2026-06-11

1. 프로젝트 개요

본 프로젝트는 Wemos D1 R1 보드를 기반으로 한 스마트 주차장 시스템이다.
입구에서는 조도센서로 차량 접근 여부를 판단하고, 내부 주차칸 2개는 초음파센서로 점유 여부를 확인한다.
빈자리가 있으면 LCD에 Gate Open을 표시하고 차단기를 열며, 만차이면 LCD에 Parking Full을 표시하고 LED 또는 부저로 경고한다.
주차 시간과 요금 계산은 별도의 Node.js Express 서버가 담당한다.

2. 현재 구현된 전체 흐름

1) 입구 차량 감지
- 조도센서가 입구 차량 접근을 감지한다.
- 현재 구현에서는 entrance_sensor.h의 isEntranceVehicleDetected()가 이 역할을 담당한다.
- 조도 기준값은 ENTRANCE_BLOCKED_THRESHOLD = 450으로 설정되어 있다.

2) 주차칸 상태 확인
- 초음파센서 2개가 각각 1번, 2번 주차칸의 점유 여부를 확인한다.
- parking_slots.h에서 readSlotDistanceCm(), isSlotOccupied(), countEmptySlots()가 관련 로직을 담당한다.
- 차량 감지 기준 거리는 SLOT_OCCUPIED_DISTANCE_CM = 5cm이다.

3) 입차 가능 판단
- 입구에 차량이 있고 빈자리가 1개 이상이면 LCD에 Gate Open을 표시한다.
- 만차 경고 LED/부저를 끄고, 서보모터를 90도로 이동시켜 차단기를 연다.
- 이 흐름은 led.ino의 loop()에서 처리한다.

4) 만차 처리
- 입구에 차량이 있고 빈자리가 없으면 LCD에 Parking Full을 표시한다.
- parking_alert.h를 통해 만차 경고 LED/부저를 켠다.
- barrier.h의 closeBarrier()로 차단기를 닫힌 상태로 유지한다.

5) 입차 등록
- 차량이 실제 주차칸에 들어가면 해당 칸 초음파센서가 점유 상태로 전환된다.
- 해당 칸 빨간 LED가 켜지고 초록 LED는 꺼진다.
- fee_request.h의 sendVehicleEntryRequest(slotId)가 호출되어 Express 서버에 GET /parking/entry?slot=칸번호 요청을 보낸다.
- 서버는 해당 칸의 입차 시간을 메모리에 저장한다.

6) 2단계 출차 처리
- 1차 감지: 차량이 주차칸에서 빠지면 해당 칸을 출차 대기 상태로 저장한다.
- 이 시점에는 아직 서버에 출차 요청을 보내지 않는다.
- 2차 감지: 차량이 차단기를 통과했다고 감지되면 confirmPendingExitAtBarrier()가 실행된다.
- 그때 sendVehicleExitRequest(slotId)를 통해 GET /parking/exit?slot=칸번호 요청을 보낸다.
- 서버 response에서 fee 값을 추출하고 LCD에 요금을 표시한다.
- 출차를 2단계로 나눈 이유는 초음파센서 흔들림이나 일시적 오감지를 바로 출차로 처리하지 않기 위해서이다.

3. 주요 파일 설명

led.ino
- Arduino 메인 스케치 파일이다.
- setup()에서 Wi-Fi, 센서, LCD, 경고 장치, 주차칸, 차단기를 초기화한다.
- loop()에서 입구 감지, 주차칸 상태 확인, 만차 처리, 차단기 제어, 출차 확정 로직을 반복 실행한다.

entrance_sensor.h
- 조도센서 입력을 담당한다.
- isEntranceVehicleDetected()는 입구 차량 대기 여부를 판단한다.
- isBarrierVehicleDetected()는 현재 조도센서 값을 재사용하여 차단기 통과 감지 역할을 한다.
- 추후 차단기 전용 센서를 추가하면 isBarrierVehicleDetected() 내부만 교체하면 된다.

parking_slots.h
- 주차칸 2개의 초음파센서와 칸별 LED를 담당한다.
- 차량이 들어오면 입차 요청을 서버에 보낸다.
- 차량이 빠지면 pendingExitSlotId에 출차 대기 칸 번호를 저장한다.
- 차단기 통과가 감지되면 서버에 출차 요청을 보내고 LCD에 요금을 표시한다.

parking_display.h
- I2C LCD 표시를 담당한다.
- Gate Open, Parking Full, 출차 요금 메시지를 출력한다.
- 같은 메시지를 반복해서 clear하지 않도록 이전 메시지를 저장하여 LCD 깜빡임을 줄였다.

parking_alert.h
- 만차 경고 LED와 부저를 제어한다.
- turnOnParkingFullAlert(), turnOffParkingFullAlert()로 상태를 변경한다.

barrier.h
- 서보모터 차단기를 제어한다.
- BARRIER_CLOSED_ANGLE = 0, BARRIER_OPEN_ANGLE = 90으로 설정되어 있다.
- openBarrier(), closeBarrier()로 차단기 상태를 바꾼다.

fee_request.h
- Wemos가 Wi-Fi에 연결하고 Express 서버에 HTTP GET 요청을 보내는 역할을 한다.
- Wi-Fi 이름, 비밀번호, 서버 주소는 이 파일 상단에서 수정한다.
- FEE_SERVER_BASE_URL은 서버 PC의 내부 IP로 바꿔야 한다.

fee-server/src/server.js
- Node.js Express 기반 요금 계산 서버이다.
- /parking/entry, /parking/exit, /parking/sessions API를 제공한다.
- 현재 주차 세션은 메모리 Map에 저장되므로 서버를 재시작하면 기록은 초기화된다.

fee-server/src/feeCalculator.js
- 주차 요금 계산 로직을 담당한다.
- 기본 30분 1000원, 이후 10분마다 500원을 추가한다.

4. 서버 API

GET /parking/entry?slot=1
- 1번 칸 입차 시간을 저장한다.

GET /parking/entry?slot=2
- 2번 칸 입차 시간을 저장한다.

GET /parking/exit?slot=1
- 1번 칸 출차 시간을 기준으로 요금을 계산한다.

GET /parking/exit?slot=2
- 2번 칸 출차 시간을 기준으로 요금을 계산한다.

GET /parking/sessions
- 현재 주차 중인 세션 목록을 반환한다.

5. 핀 설정

입구 조도센서: A0
차단기 서보모터: D5
만차 경고 LED: D0
만차 경고 부저: D8
1번 칸 초음파 TRIG / ECHO: D6 / D3
2번 칸 초음파 TRIG / ECHO: D7 / D4
1번 칸 빨간 / 초록 LED: D9 / D10
2번 칸 빨간 / 초록 LED: D11 / D12
I2C LCD: SDA / SCL

주의: Wemos D1 R1 환경에서 D9~D12 핀명이 실제 보드 설정에 따라 다르게 동작할 수 있으므로 실제 업로드 전 보드 핀맵 확인이 필요하다.

6. 실행 방법

요금 서버 실행:
cd fee-server
npm install
npm start

Wemos 설정:
fee_request.h에서 WIFI_SSID, WIFI_PASSWORD, FEE_SERVER_BASE_URL을 실제 환경에 맞게 수정한다.

Arduino 업로드:
Arduino IDE 또는 arduino-cli에서 Wemos D1 R1 보드를 선택하고 led.ino를 업로드한다.

8. 현재 남은 작업 및 주의사항

1) 실제 하드웨어 핀맵 검증
- D9~D12 핀 사용 가능 여부를 실제 Wemos D1 R1 환경에서 확인해야 한다.

2) HC-SR04 전압 처리
- HC-SR04 ECHO는 일반적으로 5V 출력이다.
- ESP8266 입력은 3.3V 기준이므로 전압 분배 회로가 필요하다.

3) Wi-Fi 및 서버 IP 설정
- FEE_SERVER_BASE_URL의 192.168.0.10은 예시값이다.
- 실제 서버 PC의 내부 IP로 변경해야 한다.

4) 차단기 통과 센서 개선
- 현재는 입구 조도센서를 차단기 통과 감지에도 재사용한다.
- 안정적인 출차 판정을 위해 차단기 전용 조도센서 또는 적외선 센서를 추가하는 것이 좋다.

5) 서버 데이터 영속화
- 현재 서버는 주차 기록을 메모리에 저장한다.
- 서버 재시작 후에도 기록을 유지하려면 JSON 파일, SQLite, MySQL 등 저장소 연동이 필요하다.
