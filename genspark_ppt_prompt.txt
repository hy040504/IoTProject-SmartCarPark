너는 발표용 PPT를 만드는 전문 프레젠테이션 디자이너다.

아래 프로젝트의 README.md, handover.txt, 현재 진행상황을 기반으로,
대학생 기말 프로젝트 발표용 PPT를 한국어로 구성해줘.
내용은 기술적으로 정확해야 하고, 과장 없이 현재 구현된 상태와 진행 방향이 잘 드러나야 한다.

프로젝트명:
스마트 주차장 시스템

반드시 반영할 핵심 내용:
- 아두이노 기반 스마트 주차장 프로젝트
- 메인 구조는 Arduino Uno 1, Arduino Uno 2, Uno 3, Node.js 서버로 구성
- Uno 1: 입구/출구 조도센서, 입구/출구 차단기 서보모터, 입출구 감지 및 제어
- Uno 2: 주차칸 초음파센서 2개, 각 칸의 LED 점유 표시
- Uno 3: LCD 전광판 역할, 주차 현황 및 출차 요금 표시
- Node.js 서버: 시리얼 통신 중계, 주차 상태 관리, 요금 계산, LCD 명령 전달, 관리자 페이지 데이터 제공
- 관리자 페이지: 실시간 주차칸 상태, 주차 시간, 세션 현황을 웹에서 확인
- 실시간 데이터 갱신이 중요한 프로젝트임
- 현재 구현된 흐름과 개발 과정, 구조 변경 이력도 포함

발표 목적:
- 기말 프로젝트 발표
- 교수님 앞에서 구조, 구현 내용, 진행 과정, 현재 상태를 설명하는 용도
- 읽기 쉽고 정리된 기술 발표자료 스타일로 작성

디자인 방향:
- 전체 톤은 깔끔하고 현대적인 대시보드 느낌
- 배경은 너무 화려하지 말고 흰색/옅은 회색/파란색 계열 중심
- 코드나 회로도, 구조도, 흐름도, 상태 화면을 시각적으로 잘 보여주는 스타일
- 텍스트 과밀 금지
- 슬라이드마다 핵심 문장만 짧게
- 발표자가 설명하기 좋도록 구조를 단순하고 명확하게
- 아이콘, 도식, 박스, 화살표, 타임라인 적극 활용
- 가능하면 실제 시스템 구조도, 보드 역할도, 데이터 흐름도, 개발 흐름도 포함
- 숫자나 상태는 표/카드 형태로 정리
- 과도한 장식은 피하고 공학 발표 느낌으로 유지

3. 시스템 전체 구조

4. 하드웨어 구성
   - 조도센서, 초음파센서, 서보모터, LCD, LED, 보드 구성 설명

5. 동작 흐름
   - 입구 감지
   - 빈자리 확인
   - 입차

   - 입구/출구 차단기
   - 조도센서 감지
   - 서버에서 받은 빈자리 수를 기준으로 입구 개방 여부 판단

7. Uno 2 역할
   - 주차칸 1, 2 점유 감지
   - LED로 상태 표시
   - ENTRY / VACATED 이벤트를 Node.js 서버로 전달

8. Uno 3 역할
   - LCD 전광판
   - 현재 주차 현황 표시
   - 출차 요금 표시

9. Node.js 서버 역할
   - 시리얼 통신 처리
   - 주차 세션 저장
   - 요금 계산
   - LCD 명령 전달
   - 관리 페이지용 실시간 상태 제공

10. 관리자 페이지
   - 웹에서 실시간으로 주차칸 상태, 주차 시간, 세션 현황 확인
   - 로그인 계정 관리
   - 모바일 대응 화면이 있다는 점도 짧게 언급
   - 대시보드 느낌으로 표현

11. 개발 진행 과정 / 방향 전환

   - Uno + Node.js 중심 구조로 전환
   - LCD 분리, 차단기 분리, 관리 페이지 추가
   - 실사용성과 안정성을 위해 구조를 단순화한 과정 설명

12. 현재 구현 상태

   - 완료된 부분과 남은 점이 있다면 간단히 구분
   - 실제 테스트 기준 중심으로 정리

13. 기대 효과
   - 주차 관리 자동화

- 발표자가 말로 설명하기 좋게 간결한 문장 위주로 작성
- 그림이나 도식을 넣을 수 있는 슬라이드는 빈 공간을 적절히 남겨줘

- 발표용이므로 실무적인 단어를 쓰되 너무 딱딱하지 않게
